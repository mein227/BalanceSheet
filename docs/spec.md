# 規格：人生資產負債表

本文件是產品行為的唯一依據。來源為 Podcast《就是愛玩股》EP435〈台股五萬點了，借錢買股會不會太危險？〉的整理筆記；時間戳 `[mm:ss]` 對應節目段落。

## 2. 計算定義（`src/calc.js`）

- **年金現值**：`P = M × [1 − (1 + r/12)^−n] ÷ (r/12)`。驗算：每月 10 萬、4%、12 期 ≈ 1,174,400（節目「117 萬多」）[03:46]。
- **人力資本**：每月收入 × 12，以年折現率 3% 折現至退休，再乘穩定度係數（穩定 1.0／普通 0.8／不穩定 0.6）。
- **流動資產**：現金／活存＋定存／貨幣基金。
- **風險資產**：股票／ETF＋其他風險投資（壓力測試時套用跌幅）。
- **緊急預備金月數**：流動資產 ÷（每月生活支出＋每月還款）。
- **還款負擔比（DSR）**：每月還款 ÷ 每月收入。
- **追繳跌幅**：`1 − 1.3 × 借款 ÷ 擔保市值`（維持率 130%）。
- **壓力測試**：風險資產與擔保品同時下跌；追繳補錢從流動資產扣除；扣完為負表示「被迫賣股」。失業可撐月數 =（流動資產 − 追繳補錢）÷ 每月支出與還款。
- **借錢試算**：B（借年金現值一次投入）vs A（每月定期定額）在持有期末的期望價值差；借 x 成時多賺與最差虧損皆為借滿的 x 倍 [17:48]。

## 3. 建議規則（`src/advice.js`）

`general` 表示一般理財原則，非出自節目。

| id | 嚴重度 | 觸發條件 | 來源 |
|---|---|---|---|
| `negative-net-worth` | danger | 淨值 < 0 | general |
| `negative-cashflow` | danger | 收入 − 支出 − 還款 < 0 | general |
| `revolving-debt` | danger | 有信用卡循環負債 | general |
| `emergency-critical` | danger | 預備金 < 3 個月 | [31:11] |
| `emergency-low` | warning | 預備金 3–6 個月 | [31:11] |
| `job-loss-uncovered` | danger | 最差情境下撐不過 6 個月 | [31:11]、[28:32] |
| `cashflow-after-income-drop` | warning | 現況為正，但收入 −30% 後為負 | [31:11] |

| `dsr-elevated` | warning | DSR 30%–40% | general、[21:21] |
| `margin-call-near` | danger | 追繳跌幅 < 40% | [26:32]、[15:15] |
| `forced-sell` | danger | 最差情境追繳金額 > 流動資產 | [31:11]、[28:32] |
| `market-debt-no-collateral` | warning | 質押／融資未填擔保市值 | [26:32] |
| `market-debt-safe` | good | 追繳跌幅 ≥ 60% | [26:32] |
| `unstable-income-debt` | warning | 收入不穩定且 DSR > 20% | [29:32]、[21:21] |
| `deep-drawdown` | warning | 最差情境淨值減少 ≥ 40% | [26:01]、[35:15] |
| `panic-seller-leverage` | danger | 自認會心裡斷頭且有市價槓桿 | [31:11] |
| `panic-seller` | warning | 自認會心裡斷頭，無市價槓桿但持有風險資產 | [31:11] |
| `compound-risk` | danger | 7 項風險因子中同時出現 ≥ 3 項 | [28:32]、[34:15] |
| `no-add-rules` | info | 持有風險資產但未事先寫好加碼規則 | [33:14]、[33:44] |
| `idle-long-term-cash` | info | 扣除 6 個月預備金後仍有長期閒置資金，且不會心裡斷頭 | [34:15]、[03:14]、[09:59] |
| `human-capital-dominant` | info | 人力資本 > 淨值 × 2 | [29:32] |
| `insurance-cash-review` | info | 有儲蓄險解約金且預備金 ≥ 6 個月 | [37:00] |
| `zero-debt-not-goal` | good | 零負債、預備金 ≥ 6 個月、現金流為正 | [21:21] |
| `healthy-structure` | good | 通過最差情境、DSR ≤ 30%、現金流非負 | [31:11] |

`compound-risk` 的 7 項風險因子：預備金 < 6 個月、DSR > 30%、追繳跌幅 < 50%、收入不穩定、會心裡斷頭、最差情境被迫賣股、最差情境現金流為負。

**健康分數**：100 − 15 × danger 數 − 7 × warning 數，下限 0。≥ 85 穩健、≥ 65 尚可、≥ 40 需要調整，其餘為高風險。

## 4. 非功能需求

- 純靜態網站，不需建置，可直接部署到 GitHub Pages。
- 不使用任何外部資源（CDN、字型、追蹤碼）；使用者資料只存在瀏覽器 `localStorage`，可匯出／匯入 JSON。
- 支援手機版面與深色模式。

## 5. 節目未說明、本工具自行假設的部分

- 「借多少」沒有具體比例公式 → 只列出各比例的利弊，不給單一答案。
- 維持率採台灣常見的 130%；實際依券商與商品而異。
- DSR 門檻（30%／40%）、人力資本折現率與穩定度係數為一般理財慣例，非節目內容。
