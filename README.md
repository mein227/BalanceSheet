# 人生資產負債表

把「未來收入」也算進資產，再用最差情境壓力測試你的財務結構。內容依據 Podcast《就是愛玩股》EP435〈台股五萬點了，借錢買股會不會太危險？〉的觀念設計。

> 長期看好，但資金結構不能讓自己活不到長期。

## 功能

- **資產負債表**：流動、風險投資、穩健投資、自用資產與各類負債，並加上「人力資本」（未來收入折現）算出人生淨值。
- **關鍵指標**：淨值、緊急預備金月數、還款負擔比、負債比、質押／融資的追繳距離、儲蓄率、目標進度。
- **壓力測試四問**：股市 −40%／−50%、收入 −30%／−50%、失業半年時，你撐不撐得住？會不會被逼著賣股？
- **分析與建議**：24 條規則，每條都標註對應的節目時間戳或「一般理財原則」。
- **借錢投資試算**：用年金現值算出今天能借多少，比較不借、借三成、借一半、借滿的期望多賺與最差虧損。
- **隱私**：沒有後端、沒有追蹤碼，資料只存在瀏覽器；可匯出／匯入 JSON。

## 本機預覽

```bash
npm run serve   # 開啟 http://localhost:8000
npm test        # 執行測試
```

因為使用 ES modules，請透過本機伺服器開啟，不要直接雙擊 `index.html`。

## 部署到 GitHub Pages

1. 到 repo 的 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**。
2. 推送到 `main`。`.github/workflows/deploy.yml` 會先跑測試，通過後才部署。
3. 網址為 `https://<帳號>.github.io/<repo>/`。

## 開發方式

這個專案按照 Harness Engineering 的思路設計，讓人類與 AI agent 都能安全地修改：

| 機制 | 檔案 | 作用 |
|---|---|---|
| 工作守則 | `AGENTS.md` | 指令、結構、不變量、新增規則的步驟 |
| 規格 | `docs/spec.md` | 觀念來源、計算定義、規則表，是行為的唯一依據 |
| 純函式核心 | `src/calc.js`、`src/advice.js` | 不碰 DOM，可直接在 Node 測試 |
| 單元測試 | `tests/calc.test.js` | 用節目數字驗算公式（例如年金現值 ≈ 117.4 萬） |
| 評測集 | `tests/fixtures/personas.js` | 9 種財務狀況，指定必須出現與不得出現的建議 |
| 不變量 | `tests/invariants.test.js`、`tests/advice.test.js` | 隱私（無網路請求）、規則可追溯、評測覆蓋率 |
| 驗證閘門 | `.github/workflows/deploy.yml` | 測試沒過就不部署 |
